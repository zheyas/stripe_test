# Django Stripe Shop

Проект для продажи товаров с помощью Stripe. Поддерживаются скидки, налоги и мультивалютность. Реализована интеграция Stripe Checkout и Stripe Payment Intent.

## Функциональность

Просмотр списка товаров
Отображение информации о товаре (описание, цена, скидка, налог)
Онлайн-оплата через Stripe (PaymentIntent)
Обработка статусов платежа: успех, ошибка, в процессе
Список заказов, скидок, налогов
Поддержка нескольких валют
## Установка

# Клонируйте репозиторий:
```
git clone https://github.com/zheyas/stripe-test.git
cd -stripe-test
```
# Создайте виртуальное окружение и активируйте его:
```
python -m venv venv
source venv/bin/activate  # или venv\Scripts\activate на Windows
```
# Установите зависимости:
```pip install -r requirements.txt```
# Создайте .env файл и добавьте ключи Stripe:
STRIPE_PUBLIC_KEY=pk_test_...
STRIPE_SECRET_KEY=sk_test_...
# Примените миграции и создайте суперпользователя:
```
python manage.py migrate
python manage.py createsuperuser
```
# Запустите сервер:
```python manage.py runserver```
Откройте http://127.0.0.1:8000/ в браузере.

# 🗺️ Маршруты приложения
```
| Путь                   | Описание                         |
|------------------------|----------------------------------|
| `/`                    | Домашняя страница                |
| `/items/`              | Список всех товаров              |
| `/item/<id>/`          | Страница товара с кнопкой оплаты |
| `/orders/`             | Список заказов                   |
| `/order/<id>/`         | Детали заказа                    |
| `/buy/order/<id>/`     | Оплата заказа через Stripe       |
| `/discounts/`          | Список скидок                    |
| `/discounts/create/`   | Создание новой скидки            |
| `/discounts/<id>/`     | Просмотр деталей скидки          |
| `/taxes/`              | Список налогов                   |
| `/taxes/create/`       | Добавление налога                |
| `/taxes/edit/<id>/`    | Редактирование налога            |
| `/taxes/delete/<id>/`  | Удаление налога                  |
| `/success/`            | Успешная оплата                  |
| `/cancel/`             | Ошибка или отмена платежа        |

```
